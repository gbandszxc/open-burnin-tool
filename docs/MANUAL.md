# 煲机助手使用手册

煲机助手（Burn-in Tool）是安卓耳机煲机工具，通过播放噪声、扫频或你导入的本地音乐，让新耳机的振膜更快进入稳定状态。本文面向使用者，讲的是各功能怎么用。想了解实现细节与构建方式，见 [README.md](../README.md)。

应用支持 Android 8.0 及以上。除检查更新和下载更新包时会匿名访问 GitHub 公开页面外，煲机功能全程离线，不需要账号，免费开源。

## 安装与获取

应用包从 GitHub Release 获取。每个版本提供两个 APK，按设备 CPU 架构（ABI）分包，没有通用包。

- `arm64-v8a`：对应 64 位设备。
- `armeabi-v7a`：对应较老的 32 位设备。

文件命名形如 `open-burnin-tool-v1.5.0-arm64-v8a-release.apk`。应用内更新也按同一口径匹配资产：优先 `arm64-v8a`，其次 `armeabi-v7a`，并且只认 release 包。如果拿不准自己的设备属于哪一档，可以直接用应用内更新，它会自动挑适配包。

从 Release 手动下载安装时，需要先允许安装未知应用。

## 方案煲机

方案煲机按固定顺序播完四个阶段，适合想按既定节奏完成一次长时间煲机的场景。方案分标准和自定义两种，下面说的阶段编排对两者都生效。

### 标准四阶段

标准方案总时长 120 小时，四个阶段依次播放。

| 阶段 | 播放内容 | 时长 | 默认响度 |
| --- | --- | --- | --- |
| 舒缓 | 白噪音 | 12 小时 | 20% |
| 适应 | 粉红噪音 | 12 小时 | 33% |
| 稳定 | 粉红噪音恒定，可替换为本地音乐 | 72 小时 | 47% |
| 轮换 | 白噪音与粉红噪音每 30 分钟交替 | 24 小时 | 60% |

### 自定义四阶段

自定义方案自己定总时长，范围 24 到 240 小时，默认 48 小时，步进按钮每次增减 12 小时。四个阶段按 10/10/60/20 的比例缩放到总时长上，也就是舒缓 10%、适应 10%、稳定 60%、轮换 20%，轮换阶段的交替周期仍是 30 分钟。

### 调整阶段顺序

四个阶段默认为舒缓、适应、稳定、轮换的顺序。想换顺序时，长按阶段行左侧的拖拽手柄拖动，松手即提交新顺序。调整结果会记住，下次打开还是这个顺序。

### 调整各阶段响度

每行行尾显示该阶段的响度，点一下可以修改，范围 1% 到 100%。默认沿用标准方案的 20%、33%、47%、60%（底层比例为 1/5、1/3、7/15、3/5），改动只影响改过的阶段，对话框里的「恢复默认」可以清掉该阶段的覆盖。

方案煲机期间，各阶段响度通过系统媒体音量体现。起播时应用会记录当时的音量，之后按阶段比例调整，暂停或结束时恢复到原音量。如果系统音量设置失败（例如处于勿扰模式），本次会话降级为播放器级增益；若进程被系统杀掉，则无法恢复原音量。所以煲机过程中系统媒体音量会变化，这是预期行为。自由煲机的响度不走系统音量，见下文。

### 稳定阶段换成本地音乐

稳定阶段默认播粉红噪音。点该行的编辑图标打开对话框，可以在「粉噪恒定」和本地音乐之间切换。选本地音乐后，可以勾选一首或多首曲目组成有序歌单，按顺序循环播放，一首播完接下一首。方案播到本地音乐阶段时，通知里的曲名会跟着刷新。

如果歌单里的某首曲子无法读取，播放时会跳过该曲、继续下一条可用曲目，不会整体回退。只有被勾选的曲目在本地音乐里被删除、导致歌单全部失效时，才会退回粉红噪音恒定；被删除的曲目也会自动从歌单中剔除。

### 配置什么时候生效

阶段顺序、响度、稳定阶段内容都是即时保存并长期记忆的。点「开始」或「继续」时，按当时的配置组装方案。续播也一样，会套用你改过的新配置。方案本身的标识不随编排变化，所以续播依然能匹配到原来的会话。

## 自由煲机

自由煲机不限定阶段，选好音源和时长就能播，适合想自己控制听什么、播多久的场景。

音源可以从下拉里选内置的 7 种合成音源，也可以选已导入的本地音乐，下拉菜单按「内置音效」和「本地音乐」分组。

时长有两种给法，二选一。预设档位是 2、8、16、24、48、72 小时，默认 8 小时；也可以自定义，范围 1 到 999 小时。

自由煲机的响度用播放器级增益表达，不会改动你的系统媒体音量。

## 音源

### 合成音源

内置 7 种合成音源，打开就能用，不需要准备文件。它们的主要区别在频谱和是否随时间变化。

| 音源 | 特点 |
| --- | --- |
| 白噪音 | 各频率能量相同，标准方案用它做舒缓阶段 |
| 粉红噪音 | 能量随频率升高而递减，低频占比较多，标准方案用它做适应和稳定阶段 |
| 正弦波 300Hz | 单一频率的纯音 |
| 方波 150Hz | 150Hz 方波，除基频外还含谐波成分 |
| 低频扫频 | 在 100 到 200Hz 之间来回扫动，40 秒一个循环 |
| 宽频扫频 | 在 100Hz 到 10kHz 之间来回扫动，74 秒一个循环 |
| 混合煲机 | 白噪音与粉红噪音各占一半 |

挑哪个主要看你关注哪段频率。只想覆盖低频，可以选低频扫频、方波或正弦波；想整段覆盖，用宽频扫频或混合煲机；白噪音和粉红噪音则是不分频点、整体铺开。

### 本地音乐

通过系统文件选择器导入音频文件。文件会被拷贝到应用私有目录，播放时循环使用，之后即使原文件被移走也不影响。导入后可以随时移除，移除会二次确认，确认后删除文件并清除对应记录。

本地音乐既能作为自由煲机的音源，也能在方案煲机的稳定阶段替换粉红噪音。

## 播放与后台

### 开始、暂停、继续、结束

点方案卡或自由煲机的开始按钮后进入播放界面，原来的配置区会被进度显示替代。播放中可以随时暂停和继续。结束需要二次确认：打开确认框时播放会暂停、已煲时长定格在那一刻，取消则自动恢复播放；但如果打开确认框前已经是手动暂停状态，取消不会自动恢复播放。

### 从检查点续播

方案煲机有未完成的会话时，对应的方案卡会显示「上次进度」，并给出两个入口。「继续」从上次已完成的秒数接着煲，「全新开始」则作废旧检查点重新计时。同一个方案最多保留一个可续检查点。

### 通知栏控制

播放时通知常驻，显示剩余时间倒计时，并提供暂停、继续、结束三个按钮。点通知会回到应用。

### 耳机拔出与来电打断

拔出耳机立即暂停。来电等短暂打断会让播放暂停，等音频焦点回归后自动继续；如果焦点被永久占用，则保持暂停，由你手动继续。

### 后台播放与恢复

播放由前台服务维持，应用退到后台后继续播放。进度每 60 秒落一次库，暂停、继续、结束、完成时也会落库。进程还在时重新打开应用，会直接回到进行中的界面，阶段和音源位置都保留。

### 完成通知

到达计划时长后，应用发出「煲机完成」系统通知，通知里显示的已煲时长定格在完成时刻，点击回到应用。这次会话被标记为已完成，应用内也会提示一次。如果没有授予通知权限，完成通知会静默跳过，不影响煲机本身。

## 进度与历史记录

记录页顶部是累计小结，显示累计煲机时长和会话次数，右边是清除入口。

下面是历史列表，每页 20 条，按开始时间从新到旧排列。滚动接近底部会自动加载下一页，列表尾部会提示已加载的总条数。每行显示这次会话的时间、状态、方案与计划时长，以及实际已煲时长。状态有四种：进行中、已暂停、已完成、已结束。

清除全部记录会先弹二次确认，确认后删除所有记录并重置累计统计，此操作不可恢复。

## 设置

### 屏幕常亮

开启后，播放界面保持亮屏。开关在煲机页顶栏和设置页都能找到。

### 不息屏模式

不息屏模式和屏幕常亮一样，播放中保持亮屏，区别在超时后的行为。打开不息屏模式，长时间没有操作时屏幕会先降到最低亮度，而不是直接熄灭。之所以需要它，是因为部分机型一旦息屏就会中断后台播放，降到最低亮度既省电又不打断煲机。

触摸屏幕、暂停或结束煲机会恢复正常亮度。暂停期间，或者屏幕常亮与不息屏模式都关闭时，亮度交还给系统管理。

### 主题

深浅色三种模式：跟随系统、强制浅色、强制深色。

### 动态取色与预置配色

Android 12 及以上可以使用动态取色，配色从系统壁纸生成，默认开启。动态取色优先于预置调色盘，低版本没有这个能力，对应开关置灰。

关掉动态取色后可以选预置调色盘，共 6 套：青瓷绿（默认）、靛蓝、琥珀暖橙、玫瑰红、森林绿、天青蓝。

### 语言

在设置页「通用」分组里的「语言」中选择，三选一：跟随系统、中文、English。默认跟随系统，中文系统显示中文，其他语言系统显示英文。切换立即生效，后台播放中的通知也会跟着换语言。选择会被记住，重启应用后保持。

## 应用内更新

应用从本仓库的 GitHub Release 获取新版本，检查时匿名访问公开页面，不需要账号、token 或任何额外配置，也不经过 GitHub API。

### 自动检查

每个进程启动时静默检查一次。发现新版本会弹窗询问「稍后」还是「下载并安装」；已经是最新版本或检查失败时，不打扰你。

### 手动检查

入口在设置页「关于」分组里的「检查更新」。点击后先显示一个「正在检查更新」弹窗，结束后结果以弹窗展示，点确认关闭。可能出现的结果有三种：

- 当前已是最新版本。
- 发现新版本，但没有适配本机的安装包。
- 检查失败，弹窗里会给出原因，例如网络不可用。

如果新版本有适配本机的安装包，弹窗会显示新版本号、适用架构和安装包名，确认就是「下载并安装」，取消即「稍后」。

### 下载与安装

下载过程有进度条、实时网速，以及已下载大小和总大小。安装包会下载到应用缓存目录，完成后交给系统安装器，由你在安装器上确认安装，不会静默安装。下载失败会清理未完成的文件并提示。如果系统尚未允许本应用安装未知应用，会引导你到系统设置页开启。

### 「稍后」的三档

自动提示时，可以选择跳过多久：

- 本次：只在当前进程内跳过，不落库，重启应用后又会提示。
- 7 天：7 天内不再自动提示，到期自动失效。
- 下个版本：只跳过当前这个版本，出现更高的新版本时仍会提示。

这三档只影响自动提示。手动检查更新不受影响，任何时候手动检查都会给出结果。

## 常见问题

### 提示「发现新版本 x.y.z，但未找到适用于当前设备架构的安装包」

这种情况是本机架构没有匹配的发布包。原因通常是该 Release 没有上传对应 ABI 的资产，或者 Release 标签的版本号与安装包文件名里的版本号不一致，导致匹配不上。可以到 GitHub Release 页面手动挑对应架构的 APK 下载。

### 安装更新时安装器报签名冲突

系统要求覆盖安装的更新包使用与已装版本相同的签名密钥，否则安装器会拒绝。请确认安装包来自同一个发布渠道，而非重签名的二次分发版本。

### 更新包下载完成却装不上

新包 versionCode 低于已安装版本时，系统安装器会拒绝降级覆盖；发布时应递增 versionCode。遇到这种情况需要等发布方修正版本号后重新发布。

### 后台煲机中途停了

部分机型在息屏后会限制或中断后台播放。可以在设置里开启不息屏模式，或同时开启屏幕常亮，避免屏幕熄灭触发限制。

### 没有收到「煲机完成」通知

应用未获得通知权限时，完成通知会静默跳过。到系统设置里为本应用开启通知权限即可。

### 检查更新失败

检查更新需要联网访问 GitHub 公开页面，网络不可用或访问受限时会失败。弹窗里会显示具体原因，可稍后重试。
